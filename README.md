# 우리 아이 놀이터

`index.html` 에서 놀이를 고름: 수학공룡(`mathdino.html`) · 수학특공대(`mathforce.html`) · 말놀이 영어·일본어·중국어(`words.html`).

## 수학공룡 놀이터

그림책 42권을 읽고 아이패드에서 하는 수학 놀이 210개. 책 한 권마다 놀이 5개.

- 아이별 기록과 월령 단계(아기·꼬마·씩씩·대장 공룡)
- 책 앞표지를 카메라에 보여 주면 그 책 놀이가 열림 (기기 안에서만 계산, 사진은 어디로도 보내지 않음)
- 내 캐릭터: 아이 얼굴 사진(만화풍 + 공룡 옷) 또는 직접 그린 그림. 말하고, 성공·띠용·완주 모습이 바뀜. 사진은 기기 안에만 저장
- 수학 키 재기: 14단계 진단 놀이로 알맞은 단계 추천 (키즈 원리셈 진단평가지가 보는 능력 순서를 참고해 새로 만든 문제)

개인이 아이와 놀려고 만든 것이며 책을 펴낸 출판사와는 관계가 없습니다. 표지 사진은 저장소에 넣지 않았고, 표지에서 뽑은 특징값(`data/refs.bin`)만 들어 있습니다.

## 수학특공대 놀이터
아람 수학특공대 본책 42권의 제목·개념(공식 상품 페이지 목차)에 맞춘 놀이 5개씩. 책 내용·그림은 쓰지 않음.

## 말놀이
주제 7개(동물·먹거리·색깔·숫자·집·자연·모양) × 놀이 5개(말 배우기·듣고 고르기·풍선·짝 맞추기·모아 듣기). 소리는 기기에 있는 음성.

## 고치는 법
`src/` 를 고친 뒤 `python3 build.py` → `index.html` 이 새로 만들어짐.

## 함께 쓴 것
- TensorFlow.js 4.22.0 (`vendor/tf.min.js`, Apache-2.0)
- MobileNet V2 1.0 224 feature vector, TF Hub (`model/`, Apache-2.0)
